## Acceptance boundaries

Contract `1.0.0` remains explicitly **DRAFT**. The clean backend artifact's contract checksum matches the web development pin. These results cannot approve an immutable release, backend freeze/conformance/package gates or previous-major compatibility. Replace the development pin through an explicit reviewed dependency update when the backend publishes its contract.

Synthetic local identity exists solely to prepare and mutate backend fixtures. This stage does not implement web Google sign-in, invitation acceptance, secure sessions, authenticated CSRF or staff workflows. Login remains disabled. Durable editor/storage/recovery, authenticated upload, review/history/trash/taxonomy/membership administration remain later stages.

The real journey covers PostgreSQL and normalized media through the local filesystem adapter/auth emulator. Real Google provider/cloud storage, a web Docker image build, deployed HTTPS, complete release secret scanning, GCP provenance, promotion/deployment/rollback and release readiness remain open. Version stays `0.0.0` with publication disabled. Manual spoken screen-reader/native browser-zoom checks remain release evidence; automated results do not establish full WCAG conformance.

Withdrawal controls subsequent reads and revalidated open tabs. Previously saved screenshots and third-party social/search caches cannot be erased by the application.
